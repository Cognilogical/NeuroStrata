## Global Constraints

- Every markdown reference to tracked work carries `(neurostrata-igg4)` so `scripts/task-coverage-gate.sh` passes cleanly.
- Unix permission APIs (`OpenOptionsExt::mode(0o600)`, `PermissionsExt::from_mode(0o600)`) are gated under `#[cfg(unix)]` so Windows builds stay clean.
- Existing `status_json()` keys (`rss_mb`, `peak_rss_mb`, `rss_available`, `growth_log`, `growth_log_threshold_mb`) remain intact while adding `profile_enabled`, `growth_supported`, and `role`.

## Review Focus

- Flipping `.with_arena_allocator(false)` to `true` or removing `init.with_execution_providers(providers)` in `FastEmbedder::new` must fail `cargo test --bin neurostrata-mcp embed`.
- Fractional sub-MB RSS byte deltas where `(a - b) / MB` differs from `(a / MB) - (b / MB)` must produce `delta_mb == rss_after_mb - rss_before_mb` in both `line()` and `sample_once_with()`.
- Pre-existing `memory-growth.log` files with permissive `0644` mode must be tightened to `0600` on `append()`, and rotated `.1` files must preserve `0600`.
- Invalid `NEUROSTRATA_RSS_LOG_MB` values must warn once rather than spamming stderr on every tool call.
- `ingest_memory_probe` must clean up a leftover `ns-probe-db-<pid>` directory at start and drop both `store` and `embedder` before measuring post-drop RSS.
