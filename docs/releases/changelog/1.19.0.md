# What's New in 1.19.0 — OntoBug W3C OWL/RDFS/SKOS/SHACL/ShEx Integration & Semantic Graph / Agentic Reasoning Capabilities A–G

> This release vendors and integrates `LadybugDB/ontobug` (`MIT OR Apache-2.0`) and the `rudof` (`0.3.21`) W3C SHACL-Core / ShEx validation engine into the workspace (`crates/ontobug`), replaces the legacy streaming Turtle SHACL parser with `ontobug::extract_shacl_shapes`, exposes `LadybugStore::ontobug_catalog` over the shared in-process `Arc<Database>`, and ships the `v1.19.0` semantic-graph and agentic-reasoning capabilities A–G with focused-test evidence and independent reviews at zero Critical/Important findings.

- **Workspace `crates/ontobug` Crate & Shared-Database `LadybugSchemaStore` / `Catalog` (`crates/ontobug/Cargo.toml`, `crates/ontobug/src/lib.rs`, `crates/ontobug/src/ladybug.rs`, `crates/ontobug/src/catalog.rs`, `src/store/ladybug.rs`, `Cargo.toml`, `neurostrata-wy2r`).** Vendors upstream `LadybugDB/ontobug` (`0.1.0`, `MIT OR Apache-2.0`) into `crates/ontobug` aligned to workspace dependencies (`lbug = "0.22.3"`, `oxigraph = "0.5.11"`, `oxrdf = "0.3.4"`, `oxrdfio = "0.2.6"`, `rudof` `0.3.21` crates `rudof_rdf`, `rudof_iri`, `shacl`, `shex_ast`, `shex_validation`) with `default = []` so CLI/Python bindings are never compiled into the server binary. Adds `LadybugSchemaStore::from_database(Arc<Database>, path)` and `Catalog::from_database(Arc<Database>, path)` plus `LadybugStore::ontobug_catalog()` / `LadybugStore::with_ontobug_catalog(...)` synchronized under `LadybugStore::write_lock` so ontology schema tables (`SchemaEntry`, `OntologyClass`, `OntologyProperty`, `ShaclShape`, `ShaclProperty`, `Namespace`, `RdfNode`, `Statement`) and property-graph DDL share the existing open `LadybugStore` handle instead of opening a conflicting second `Database::new` lock.
- **`rudof` W3C SHACL-Core & ShEx Validation + `OntologyIndex::load_shacl_shapes` Replacement (`crates/ontobug/src/validate.rs`, `src/rdf/shacl.rs`, `src/rdf/ontology.rs`, `src/schemas/shacl/memory-shapes.v1.ttl`, `src/schemas/shacl/fact.ttl`, `src/schemas/shacl/rule.ttl`, `src/schemas/shacl/attempt-shapes.v1.ttl`, `src/schemas/shacl/edge-shapes.v1.ttl`, `src/schemas/shacl/topology-shapes.v1.ttl`, `src/schemas/shacl/mesh-record-shapes.v1.ttl`, `src/schemas/shacl/multimodal-shapes.v1.ttl`, `neurostrata-wy2r`).** Replaces the ~310-line hand-rolled streaming Turtle SHACL parser in `OntologyIndex::load_shacl_shapes` with `ontobug::extract_shacl_shapes`, adds `OntologyIndex::validate_rdf_graph` and `src/rdf/shacl.rs` helpers (`validate_rdf_with_ontobug`, `validate_shex_with_ontobug`) backed by `rudof` `0.3.21`, and normalizes all eight embedded `.ttl` shape files in `src/schemas/shacl/` (`sh:in` RDF list literal domains and numeric `sh:minInclusive` literals) for strict W3C SHACL-Core conformance.
