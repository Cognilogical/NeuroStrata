# What's New in 1.18.0 — Subject-Matter Domain Expertise, Enterprise Ontology & Code Intelligence

> This release introduces the Subject-Matter Domain Expertise & SKOS Concept Taxonomy Engine (`neurostrata_taxonomy`), the Enterprise Ontology Engine (`neurostrata_action`, the digital-twin tools `neurostrata_twin_get`, `neurostrata_twin_set`, `neurostrata_twin_diff`, `neurostrata_twin_list`, and `neurostrata_scenario`), the Code Intelligence Suite (`neurostrata_ingest_scip`, `neurostrata_diff_tour`, `neurostrata_insights`, `neurostrata_locate`, `neurostrata_object_view`, cross-file call resolution), normative hybrid retrieval slot reservation, and ingest memory/UTF-8 resilience fixes.

- **Subject-Matter Domain Expertise, SKOS Taxonomy & SME Frontier Advisor (`neurostrata-f0bn`, `neurostrata-ih7f`).** Projects can now encode an explicit domain thesis (`set_thesis`), curate a W3C SKOS concept hierarchy (`upsert_concept`), synthesize token-bounded epistemic briefings (`briefing`), benchmark against SPDX license-verified comparable implementations (`compare`), audit structural epistemic gaps (`gaps`), and generate ranked architectural/domain improvement recommendations with external research agendas (`advise`). Public-safe briefings auto-inject into `neurostrata_get_snapshot` and `subagent_prompt_injection`, and shareable `thesis`/`concept` rows replicate across SynapticMesh.
- **Enterprise Ontology Engine (`neurostrata-1mus`: `neurostrata-8328`, `neurostrata-d0fb`, `neurostrata-0n6q`).** Adds fail-closed kinetic action types with atomic bitemporal receipts and reverse-order revert (`neurostrata_action`), polymorphic digital twin interfaces with monotonic bound intersection and total rollup reducers (`neurostrata_twin_get`, `neurostrata_twin_set`, `neurostrata_twin_diff`, `neurostrata_twin_list`), and copy-on-write sandboxed what-if simulation overlays (`neurostrata_scenario`) whose operations are `create`, `stage_memory`, `stage_twin`, `apply_action`, `evaluate_sparql`, `diff`, `commit`, `drop`, and `list`.
- **Compiler-Grade Code Intelligence (`neurostrata-rbde`, `neurostrata-737r`, `neurostrata-r3as`, `neurostrata-kx2n`).** Resolves cross-file `calls` edges via a two-pass workspace symbol table (`SAME_FILE > IMPORTED_FILE > WORKSPACE_UNIQUE`), ingests compiler-verified `.scip` indexes (`neurostrata_ingest_scip`), analyzes PR diffs into 4-stop guided architectural tours with blast-radius and rule-governance checks (`neurostrata_diff_tour`), locates code and governance anchors with a compound finder (`neurostrata_locate`), hydrates a unified ontology object view (`neurostrata_object_view`), and computes bitemporal codebase insight series (`neurostrata_insights`).
- **Ingest Resilience & Normative Retrieval Guarantees (`neurostrata-17uu`, `dfba303`).** `FastEmbedder::embed_batch` now bounds ONNX sub-batching (`FAST_EMBED_BATCH_SIZE = 1`) and truncates `DocSections` prior to embedding so full-workspace ingestion runs within `~1.9 GB` RSS instead of OOM-allocating padded `256 × 2048` self-attention tensors. `SecretScanner::detect_jwt` uses `Regex::find_iter` to avoid UTF-8 slice boundary panics around multi-byte characters, and `neurostrata_search_memory` reserves normative memory slots so AST symbols never crowd out architectural rules or domain concepts.
- **Formal Verification (`proofs/`, `src/formal_kernel.rs`, `tests/lean_parity_test.rs`).** Extends the Lean 4 (`v4.35.0`) proof suite and standalone Rust formal kernel with 8 new verified domains (including inductive multi-step `DirectedWalk` cycle-freedom and SKOS disjointness theorems in `NeuroStrata/Taxonomy.lean`) and `1,011` exhaustive Rust-to-Lean parity rows.
