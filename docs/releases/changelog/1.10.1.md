# What's New in 1.10.1 — Retirement Coherence

- Successor rule: work belongs to the row at end of supersession chain (bounded 32, cycle-safe); readiness / extraction obligation / snapshot all use one rule.
- Retired lesson discharges nothing; lesson belongs to work not to one row id.
- `task_list` hides retired by default (`retired: true` only under `include_retired: true`).
- Claim = lease on work (not row id); supersede reply names successor id + release call.
