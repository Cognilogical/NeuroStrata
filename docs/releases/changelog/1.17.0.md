# What's New in 1.17.0 — NeuroMesh Real-Time Transport & Autonomous Memory Control Plane

- **NeuroMesh near-real-time multi-agent cognitive mesh transport (`src/synaptic_mesh/`, `#63`).** SynapticMesh now streams signed `MeshFrame` envelopes (`RuleFactProcedure`, `TwinDelta`, `LeaseClaim`, `ConflictNotice`, `SyncHello`, `SyncRangeRequest`) in near-real-time alongside git bundle snapshots:
  - **Pluggable `MeshTransport` trait (`src/synaptic_mesh/transport.rs`)** with `publish`, `subscribe`, `claim_lease`, and `status`.
  - **Default pure-Rust P2P transport (`src/synaptic_mesh/p2p.rs`)** using `tokio::net` TCP length-prefixed framing, AES-256-GCM wire encryption (`openssl::symm`) with 96-bit CSPRNG nonces mixed with node-ID SHA-256 prefix and monotonic counter, and `nsmesh1...` Ed25519-signed capability invite tokens.
  - **Optional NATS transport (`src/synaptic_mesh/nats.rs`, `--features nats-mesh`)** speaking the TCP NATS wire protocol (`CONNECT`, `HPUB` with `Nats-Msg-Id` deduplication headers, `SUB neuromesh.> 1`, `MSG`/`HMSG`, `PING`/`PONG`).
  - **Single-writer `frames.wal` outbox and causal `MeshReactor` (`src/synaptic_mesh/outbox.rs`, `src/synaptic_mesh/reactor.rs`)** enforcing 3-gate sovereignty (`eligibility: shareable`, permitted memory types `rule`/`fact`/`procedure` with `TaskDelta` rejected on both egress and ingress, recursive procedure runtime counter stripping, and Ed25519 signature verification), per-origin contiguous sequence tracking with reorder buffering, non-destructive conflict preservation (`mesh.conflict = true`), and LWW `(hlc_ts, origin_node_id)` merge for `TwinDelta` world-state records.
  - **Active-context `AttentionFilter` (`src/synaptic_mesh/attention.rs`, `src/server.rs`)** tracking each MCP session's recent files, symbols, and tags and prepending `[NeuroMesh Δ]` notices only when an inbound peer mutation intersects that session's working set.
  - **Persistent CLI mesh runtime (`src/synaptic_mesh/cli.rs`)** adding `neurostrata-mcp synaptic-mesh up`, `join-token`, `invite`, and `peers`.
- **Autonomous Memory Control Plane — Waves 1–5 (`plugins/core/`, `src/task/harness_plugins.rs`, `#62`).** Upgrades `@neurostrata/plugin-core` across OpenCode, Claude Code, Codex, and GitHub Copilot CLI with global OpenCode config propagation, V2 hook alignment, automatic semantic recall and task intake on user turns, structured failure/decision capture, and multi-harness CI verification.
- **SynapticMesh bundle hardening & cross-platform CI fixes (`#48`, `#51`, `#53`, `#54`, `#55`, `#56`, `#57`, `#59`, `#60`, `#61`).** Hardens bundle signature timing, validation gates, and rollback refusal, clears 9 RUSTSEC advisories, gates Unix-only test APIs on Windows, and stabilizes federation test sockets.
