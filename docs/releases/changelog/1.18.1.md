# What's New in 1.18.1 — Taxonomy, Kinetic Action, WAL Recovery, Connector & Release Hardening

> This release ships all downstream hardening, correctness fixes, performance improvements, and CI/release governance updates landed on `main` since **v1.18.0**.

- **Pluggable Workflow Connectors & 3-Tier Documentation Manifest Gate (`src/workflow/`, `src/doc_gate.rs`, `docs/manifest.json`, `#206`).** Extracts `WorkflowStage`, `WorkflowEvent`, `WorkflowConnector`, `GitWorkflowConnector`, and `ManifestWorkflowConnector`, routing task-gate scope and lifecycle hook execution through the active connector, and adds `neurostrata-mcp doc-gate` to enforce the 3-tier documentation layout (`docs/vision/`, `docs/features-api/`, `docs/extend/`, `docs/archive/`), required API/trait tokens, and surface-diff co-change rules.
- **Taxonomy, SynapticMesh & Auto-Briefing Hardening (`src/rdf/taxonomy.rs`, `src/synaptic_mesh/import.rs`, `#230`, `#246`, `#249`, `#254`, `#257`, `#258`, `#259`).** Namespace-qualifies `thesis` and `concept` row IDs (`thesis_row_id` and `concept_row_id`) so multiple namespaces in a shared `LadybugStore` never collide; preserves independent foreign-authored `thesis` and `concept` mesh creations in `.conflicts` during SynapticMesh import instead of overwriting local un-exported rows; and optimizes `neurostrata_get_snapshot` and task auto-briefing to probe active, non-conflicting, unrestricted `"concept"` then `"thesis"` rows by type (skipping the full namespace and edge read when no visible taxonomy rows exist or when a namespace is thesis-only, short-circuiting concept-present namespaces after one typed probe, and conservatively falling back to the full read on probe errors).
- **Kinetic Action Revert, SHACL Upsert Post-Image & DataConnector Pool Persistence (`src/rdf/action.rs`, `src/connectors/mod.rs`, `src/kernel/mod.rs`, `#247`, `#248`, `#250`, `#251`, `#252`, `#255`).** Resolves multi-effect `SetTwinState` revert before-images against staged rows so sibling effects targeting the same digital twin revert cleanly; aligns `execute_revert` active-head selection with `load_active_rows_and_edges`; validates the full caller-supplied `UpsertMemory` metadata post-image during `neurostrata_action` stage-5 SHACL verification; and pre-seeds default `local-fs` and `http-fetch` pools in `DataConnectorRegistry` with persistent `connectors.json` pool registration across CLI invocations.
- **Zero-Action Start & Pre-Commit Hook Path Matching (`src/server.rs`, `src/task/mod.rs`, `scripts/hooks/pre-commit`, `#236`, `#243`, `#253`).** Resolves MCP task-claim worktree scope from caller-supplied `project_root` / `path` / `file_path` / `directory` before falling back to daemon `startup_root`, exempts read-only git inspection plus `git push` / `git pull` / `git fetch` shell segments from Zero-Action Start while rejecting mutating git subcommands and subshell expansions, and normalizes relative, `./`-prefixed, and absolute paths in `scripts/hooks/pre-commit`.
- **WAL Recovery Accounting, No-Open Backup Safety & Ingest/Recall Resilience (`src/store/ladybug.rs`, `src/storage/`, `src/embed.rs`, `src/parser/ingest.rs`, `src/server.rs`, `#207`, `#209`, `#211`–`#214`, `#219`, `#220`, `#224`, `#228`, `#233`–`#235`, `#237`, `#244`, `#245`).** Unifies zero-record WAL recovery accounting, classifies a removed `.wal.replay-check` shadow as `replayed` only on positive replay evidence, hardens `backup --no-open` / `verify-snapshot` / `restore` against uncoordinated live-daemon copies and symlink traversal, isolates single-item embedding and ingest failures, ranks rule enforcement ahead of fan-out while bounding the `linked_files` census query, tokenizes each row once in `detect_conflicts`, probes Podman lazily on first sandbox use, and returns JSON-RPC `-32601` for unknown MCP methods.
- **CI, Release Reference Validation & Merge-Gate Governance (`.github/workflows/ci.yml`, `.github/workflows/release.yml`, `scripts/gate-receipt.sh`, `scripts/check-release-references.sh`, `scripts/enforce-main-ruleset.sh`, `scripts/main-ruleset.json`, `docs/features-api/ops/merge-gates.md`, `web-ui/package.json`, `#210`, `#215`–`#218`, `#225`–`#227`, `#229`, `#231`, `#232`, `#238`–`#240`, `#256`, `#259`).** Pins CI actions and Rust toolchain, adds `cargo-audit` and disk-hygiene gates, hardens `scripts/gate-receipt.sh` to fail closed on unresolved P1/P2 review threads and base-branch diffs, validates release narratives against source registries in CI (`scripts/check-release-references.sh`), syncs GitHub Release bodies from `docs/releases/changelog/${TAG#v}.md`, codifies the `main-merge-gate` ruleset, and scopes `@tailwindcss/vite` to `devDependencies` in `web-ui/package.json`.
