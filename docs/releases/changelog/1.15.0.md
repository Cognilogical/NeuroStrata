# What's New in 1.15.0 — Zero-Touch Harness Auto-Install, 6 CLI Harness Plugins, Automatic Graph-First Reflex & Full 60-Wave Hardening

- **Zero-Touch Harness Detection & Plugin Auto-Install (`src/task/harness_plugins.rs`):** On init (`neurostrata_bootstrap`, `neurostrata_task_setup`, and `neurostrata_get_snapshot`), `neurostrata-mcp` automatically detects the active/installed CLI agent harness (`opencode`, `openclaw`, `claude`, `hermes`, `codex`, `github-cli`) from environment and project markers, extracts the embedded zero-dependency plugin bundle into `.NeuroStrata/plugins/<harness>/`, and wires the harness config files with zero user involvement.
- **6 Zero-Dependency CLI/Terminal Agent Harness Plugins (`plugins/`):** Shipped compiled zero-dependency bundles and unit tests (61/61 passing) for OpenCode, Claude Code CLI, Hermes Agent CLI, OpenAI Codex CLI, GitHub Copilot CLI (`gh`), and OpenClaw—enforcing pre-flight snapshot, Zero-Action Start, Graph-First lookup nudges, Breath checkpoints, turn-end deferred-work detection, and automatic subagent prompt context injection.
- **Automatic Graph-First Exploration & Subagent Context Propagation (`src/task/mod.rs`, `src/server.rs`):** `neurostrata_task_create` and `neurostrata_task_claim` automatically compute hybrid vector + 1-hop graph context (`auto_retrieved_context`) and return a ready-to-paste `subagent_prompt_injection` block; all 8 graph/memory lookup tools record per-task and per-session telemetry (`graph_queries_count` and `.NeuroStrata/session_queries.json`).
- **Seamless Upgrade & Lifecycle Delta Engine (`src/task/wiring.rs`, `src/store/ladybug.rs`):** `neurostrata_get_snapshot` infers `project_root` when omitted, auto-heals both `pre-commit` and `pre-push` git hooks, backfills schema defaults on startup, and reports `LIFECYCLE & HOOK DELTA` whenever new wires or triggers are introduced by a binary upgrade.
- **Full 60-Wave Codebase Audit & Zero-Flags Architecture:** Audited and hardened all 51 root modules in `src/` with zero Cargo feature flags, zero runtime capability-toggle booleans, zero `#[allow(dead_code)]`/`#[allow(unused_imports)]` suppressions, zero production `.unwrap()`/`.expect()` calls, W3C RDF/SPARQL 1.1/OWL 2 RL/SHACL validation via OxiRS, and local Laya duplicate judgment + centroid-margin training.
- **Daemon Caller-Path Authority (`src/daemon.rs`, PR #36 / `neurostrata-p1ex`):** Integrated `check_caller_path`, `resolve_caller_path`, `load_allowed_external_dirs`, and `caller_path_refusal` across `/ingest`, `/backup`, `/export-graph`, and `/tasks/import` so every caller-supplied filesystem path is canonicalized (handling non-existent leaf targets and symlinks) and verified against `startup_root` or `allowed_external_dirs` before use.
