P0 VERIFIED CONSENSUS Temporal Memory Expiry Is Semantically Broken
server.rs:349-351, 395-397 · ladybug.rs:151

The valid_to check only tests whether the field is absent or null. A memory expired in 1970 (valid_to = 1) and one expiring in 2099 (valid_to = 9999999999) are treated identically — both "active". Expiration is completely inert.

// BROKEN: presence check, not time comparison
all_memories.retain(|r| {
    r.payload.metadata.get("valid_to").is_none()
        || r.payload.metadata["valid_to"].is_null()
});
// FIX: compare against current timestamp
let now = chrono::Utc::now().timestamp();
all_memories.retain(|r| {
    r.payload.metadata.get("valid_to")
        .and_then(|v| v.as_i64())
        .map(|t| now < t)       // active if expiry is in the future
        .unwrap_or(true)        // no expiry = always active
});
▶
P0 VERIFIED CONSENSUS Synchronous Filesystem Calls Block the Tokio Event Loop
server.rs:596, 603

std::fs::create_dir_all and std::fs::write inside async fn start_mcp_server block the tokio worker thread. During canvas generation over large namespaces, the MCP stdin reader stalls, causing client timeouts.

// BROKEN — sync fs in async context
let _ = std::fs::create_dir_all(&vault_dir);
if std::fs::write(&canvas_path, canvas_str).is_ok() { ... }
// FIX — use tokio::fs
tokio::fs::create_dir_all(&vault_dir).await?;
tokio::fs::write(&canvas_path, canvas_str).await?;
▶
P0 VERIFIED Kuzu Query Injection via Backslash Escaping
ladybug.rs:73-91

All 9 query parameters are escaped with a single-quote replacement. A trailing \ in any field renders the Cypher string literal unterminated, crashing the query. Even without injection, this is a DoS vector — any agent can crash memory storage by including a backslash in content.

// VULNERABLE — trailing backslash breaks string literal
let safe_id = id.replace("'", "\\'");
// id = "abc\" → safe_id = "abc\'" → query: WHERE id = 'abc\'' ← malformed
// MINIMAL FIX — also sanitize backslashes
fn sanitize(s: &str) -> String {
    s.replace('\\', "\\\\").replace('\'', "\\'")
}
// PREFERRED: Use Kuzu parameterized query API once stable

P1 VERIFIED Panic on Non-UTF8 DB Path at Startup
main.rs:25, 206

.to_str().unwrap() on a PathBuf panics if the path contains non-UTF8 bytes (valid on Linux). The server crashes at startup with no recoverable error.

// BROKEN
LadybugStore::new(config.db_path.to_str().unwrap().to_string(), ...)
// FIX
LadybugStore::new(config.db_path.to_string_lossy().to_string(), ...)
▶
P1 VERIFIED PLAN_RISK access_count Neural Gain Feature Is Permanently Inert
server.rs:280 · ladybug.rs:155-156

access_count is initialized to 0 on every upsert and read to compute a "neural gain" score boost (distance - (access_count * 0.05)) in search(). However, no code path anywhere in the codebase increments access_count after a memory is accessed. The neural frequency feature is entirely non-functional — every memory has a perpetual boost of 0.

P2 VERIFIED Directory Traversal Performed Twice; Skip Logic Duplicated
ingest.rs:24-127, 129-242

ingest_directory builds two independent WalkBuilder instances over the same path. The skipped_dirs array (9 items) is duplicated verbatim. For a large project, this doubles I/O. Merge into a single pass or refactor the skip predicate into a shared closure.

P2 VERIFIED Structurally Fragile .unwrap() on JSON Serialization
server.rs:75, 176, 792

Three identical serde_json::to_string(&resp).unwrap() calls. Safe today since Value is always serializable, but structurally fragile — a future type addition to the response struct would cause a silent production panic with no JSON-RPC error response to the caller.

✓ Strengths Noted by Panel

  • • Namespace anti-hallucination lock (server.rs:287-293) — genuinely novel and effective safety mechanism. Highest-quality feature in the codebase.
  • • Clean trait abstraction (traits.rs) — Embedder/VectorStore are well-designed. Swapping backends requires zero business logic changes.
  • • Kuzu MERGE semantics — idempotent upsert by design. The migration from LanceDB is architecturally sound.
  • • GraphRAG neighborhood fetch (ladybug.rs:175-218) — 1-hop graph expansion on search is a strong cognitive retrieval pattern.
